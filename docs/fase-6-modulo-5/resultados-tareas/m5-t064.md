# M5-T064 — Formulario conectado de plazos y recordatorios

Verificación del 22 de noviembre de 2026 sobre backend `d725ef2` y frontend `b7cdb53` más los cambios de este lote. El formulario consume las rutas existentes de [M5-T063](m5-t063.md).

## Flujo

El Administrador abre **Configurar plazos** en **Mi cuenta**. El editor carga los valores vigentes y su versión, comprueba rangos enteros de 6–24 horas para confirmar y 12–48 para recordar, y guarda ambos como un solo reemplazo. El 400 conserva el borrador y muestra el error. El 409 también conserva el borrador y exige una lectura explícita de la configuración vigente antes de volver a guardar. Las citas, condiciones y recordatorios que ya tenían una política asignada conservan sus datos.

El código se encuentra en `frontend-saas`. El editor compartido maneja los estados y el foco, sus estilos usan el acento del panel, la vista de cuenta limita el acceso al Administrador y sus acciones llaman a la API con la sesión vigente. La configuración de demo reutiliza el diálogo con datos en memoria por negocio. La nota `docs/automatizaciones-configuracion-m5-t064.md` describe cada archivo y el flujo completo.
