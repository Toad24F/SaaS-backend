# M5-T115–T118 · Pantalla de reportes y colección de impresión

Fecha de verificación: 23 de noviembre de 2026. Revisiones base: frontend `f7a9462` y backend `c197893`.

## Flujo y alcance

Administración elige el periodo, la sucursal, el Profesional, el servicio y la agrupación. El frontend crea el corte con `POST /reportes/cortes` y consulta el resumen y la primera página antes de presentar cifras. Utiliza los indicadores, denominadores, importes históricos y nombres devueltos por el servidor. Se distinguen carga, vacío y fallo.

La paginación usa `GET /reportes/cortes/:id/filas` con los metadatos del mismo corte. Un 404 retira el resultado y pide generar un corte. La preparación de impresión vuelve a recorrer las páginas y verifica que cada una pertenezca al corte, que los tamaños y el total concilien y que cada cita sea única. La colección se publica completa para habilitar el diálogo del navegador.

El cambio funcional reside en el frontend. Este archivo registra la evidencia y `tareas.md` enlaza el cierre. La [nota del frontend](../../../../frontend-saas/docs/fase-6-modulo-5/reportes.corte.md) describe cada archivo de interfaz y prueba. El diseño final de impresión, el aviso del menú nativo y la comprobación de un PDF guardado corresponden a T119–T121.
